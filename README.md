# WhileWork
Агрегатор вакансий, создающий удобную мост-платформу между соискателями и актуальными предложениями на рынке труда.

### Стек и технологии
- **Бэкенд**: Django, FastAPI, RabbitMQ
- **Пайплайны и обработка данных**: Airflow
- **Данные**: Redis, PostgreSQL

### Целевая аудитория: 
- IT-специалисты и digital-направление в странах СНГ
